Record3D live-streamed video from your iPhone/iPad

Works best with Google Chrome or Safari. You may experience issues when using Firefox.

For more details, visit https://record3d.app/features

NOTE: This demo uses a Web Worker and the Encoded Transform API to parse exactly synchronized per-frame metadata (camera intrinsics and pose data). Make sure you run this demo on a server and NOT using the file:// URI, otherwise the worker won't work!

Open the inspector / console to see the live log of per-frame metadata.
